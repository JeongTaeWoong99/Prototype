## 프로젝트 소개
Unity 기반으로 제작된 프로젝트이며, 대회 참가를 목적으로 제작되었습니다. 

2D 플랫포머 게임의 기본 구조를 직접 구현하는 데에 중점을 두었습니다.

이후, 해당 프로젝트를 기반으로 ZETA 프로젝트로 확장 및 발전하였습니다.
